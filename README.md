# Avatice (آواتک) 3D WebGPU Experience

A cinematic, full 3D website for Avatice, a Persian digital marketing agency. Built with **Three.js WebGPURenderer** and **TSL (Three.js Shading Language)**.

## Getting Started

### Running the Project
To start the local development server:
```bash
npm start
```
The site will be available at http://localhost:8000.
